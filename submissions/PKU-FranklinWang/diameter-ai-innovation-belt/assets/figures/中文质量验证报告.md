## 三、乱码图件说明

### site-overview.png 和 land-use-structure.png

- **问题**：中文字符显示为方块（□），即 tofu/乱码
- **原因**：原生成脚本使用 `plt.rcParams['font.sans-serif']` 设置字体名，但 TTC 字体集合文件通过 `addfont()` 仅注册第一个 JP 变体的家族名，SC 变体无法通过名称匹配
- **建议修复方案**：改用 `FontProperties(fname='/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc')` 方式逐文本指定字体文件路径
- **备注**：此两张为既有图件，不在本次任务的生成范围内，如需修复请告知

## 四、技术方案总结

### 字体加载最佳实践（matplotlib + Noto Sans CJK SC）

```python
from matplotlib import font_manager
from matplotlib.font_manager import FontProperties

font_path = '/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc'
bold_font_path = '/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc'
font_manager.fontManager.addfont(font_path)
font_manager.fontManager.addfont(bold_font_path)

cn_font = FontProperties(fname=font_path)
cn_font_bold = FontProperties(fname=bold_font_path)

# 使用方式
ax.text(x, y, '中文文本', fontproperties=cn_font)
```

**注意事项**：
- 禁止仅使用 `plt.rcParams['font.sans-serif'] = ['Noto Sans CJK SC']`，TTC 文件 addfont 只注册第一个 JP 变体
- 粗体需单独加载 Bold TTC 文件
- 所有中文文本必须显式指定 `fontproperties` 参数
